# Ruta de aprendizaje

**Dedicación prevista:** 5-7 horas semanales.  
**Método:** teoría breve, ejercicios, aplicación al proyecto y repaso.

Los tiempos son orientativos. Avanzar cuando los conceptos se comprendan y puedan aplicarse, no solo cuando haya pasado un número de semanas.

## Bloque 1 — Fundamentos de Python

**Estado:** pendiente / en preparación.

Temas:
- Variables, tipos y operadores.
- Condicionales y bucles.
- Funciones y parámetros.
- Listas, tuplas, conjuntos y diccionarios.
- Cadenas y comprensión de colecciones.
- Archivos y excepciones.
- Módulos, paquetes y entornos virtuales.
- Clases, objetos, métodos y encapsulación.

Práctica del proyecto:
- Crear un menú de consola.
- Crear conversaciones.
- Añadir mensajes a una conversación.
- Listar conversaciones y mensajes.
- Separar el código en funciones y clases cuando tenga sentido.

Criterio de salida:
- Poder explicar y modificar el programa sin depender de copiar una solución completa.

## Bloque 2 — Bases de datos y SQLite

**Estado:** pendiente. Prioridad reforzada por las carencias identificadas.

Temas:
- Tablas, filas y columnas.
- Tipos de datos.
- Claves primarias y foráneas.
- Relaciones uno a muchos y muchos a muchos.
- Restricciones y valores únicos.
- SELECT, INSERT, UPDATE y DELETE.
- WHERE, ORDER BY y JOIN.
- Transacciones básicas.
- Conexión a SQLite desde Python.

Práctica del proyecto:
- Crear tablas de conversaciones y mensajes.
- Relacionar cada mensaje con su conversación.
- Guardar y recuperar el historial.
- Evitar pérdida de datos al cerrar el programa.

Criterio de salida:
- Diseñar un esquema sencillo y realizar operaciones CRUD desde Python.

## Bloque 3 — HTTP, APIs REST y JSON

**Estado:** pendiente.

Temas:
- Cliente y servidor.
- HTTP y HTTPS.
- Métodos GET y POST.
- Códigos de estado.
- Cabeceras y cuerpo de una petición.
- JSON.
- Peticiones desde Python con `requests`.
- Manejo de errores, tiempos de espera y respuestas inválidas.

Práctica:
- Consumir una API de prueba.
- Enviar datos JSON y procesar la respuesta.
- Separar la lógica de comunicación del resto del programa.

Criterio de salida:
- Poder explicar qué envía el cliente, qué responde el servidor y cómo se gestiona un error.

## Bloque 4 — Modelos LLM y Ollama

**Estado:** pendiente.

Temas:
- Qué es un modelo de lenguaje.
- Tokens, contexto y límites.
- Mensajes de sistema, usuario y asistente.
- Modelos locales y cuantización.
- Instalación y uso de Ollama.
- API local de Ollama.
- Historial conversacional.
- Uso de herramientas o llamadas a funciones.

Práctica:
- Ejecutar un modelo compatible con el hardware.
- Enviar mensajes desde Python.
- Mostrar respuestas.
- Mantener una conversación con contexto.

Criterio de salida:
- Tener un chatbot local funcional y explicar cómo se comunica Python con Ollama.

## Bloque 5 — Interfaz gráfica y arquitectura

**Estado:** pendiente.

Temas:
- PySide6 y widgets.
- Señales y slots.
- Diseño de ventanas.
- Separación de interfaz y lógica.
- Hilos o tareas asíncronas para no bloquear la interfaz.
- Configuración y registros.

Práctica:
- Ventana de chat.
- Campo de entrada y botón de envío.
- Historial visual.
- Indicador de espera y gestión de errores.

## Bloque 6 — Memoria y voz

**Estado:** pendiente.

Temas:
- Historial persistente.
- Preferencias del usuario.
- Diferencia entre historial, contexto y memoria.
- Búsqueda de información relevante.
- Embeddings y RAG cuando sean necesarios.
- Reconocimiento de voz.
- Síntesis de voz.

Práctica:
- Recuperar conversaciones anteriores.
- Guardar preferencias explícitas.
- Enviar audio a un sistema de reconocimiento.
- Reproducir respuestas habladas.

## Bloque 7 — Herramientas y automatización

**Estado:** pendiente.

Temas:
- Diseño de herramientas con parámetros definidos.
- Validación de entradas.
- Acceso controlado a archivos.
- Apertura de aplicaciones.
- Permisos y confirmaciones.
- Registro de acciones.
- Pruebas de seguridad.

Práctica:
- Crear una lista limitada de herramientas permitidas.
- Permitir que el modelo solicite una herramienta.
- Validar la solicitud antes de ejecutarla.
- Confirmar acciones sensibles.

## Bloque 8 — Integración y acabado

**Estado:** pendiente.

Temas:
- Pruebas unitarias e integración.
- Gestión de configuración.
- Empaquetado para Windows.
- Rendimiento y uso de memoria.
- Documentación de instalación.
- Copias de seguridad y versiones.

## Distribución semanal sugerida

- 1,5 h: teoría y apuntes.
- 2 h: ejercicios pequeños.
- 2 h: proyecto.
- 1 h: repaso, pruebas y documentación.

## Registro de avance

Actualizar este documento después de cada revisión. No marcar una materia como dominada solo por haber leído su explicación.
